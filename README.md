# Pose It! - real-time pose detection application  

 Pose It! is a user-friendly application desigend on python utilizing MediaPipe and OpenCV for human pose estimation and visualization. The tool features a modern GUI developed with Tkinter and CustomTkinter, allowing users to upload videos and view side-by-side comparisons of the input and processed outputs. Designed for applications in sports analytics, fitness tracking, and research, it provides an intuitive and dynamic experience for exploring pose detection technology.

🔍 Key Features:
Real-Time Pose Detection: Using MediaPipe for pose estimation capabilities, this tool processes videos and overlays skeletal landmarks on detected human poses.
Side-by-Side Comparison: Display both the original input video and the processed output video simultaneously for better insights.
Intuitive User Interface: The GUI with easy-to-navigate controls, making it accessible to users of all levels.

This project combines the power of computer vision with a seamless user experience, making it ideal for applications in sports analytics, fitness tracking, and research.
